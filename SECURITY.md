# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in this project, please report it via the GitHub Issues tab. Describe the issue clearly, including steps to reproduce and potential impact. We will review and address security concerns promptly.

## Responsible Disclosure

We encourage responsible disclosure. Please avoid sharing details publicly until a fix is released.

## Scope

This project processes audio and subtitle data locally. No user data is sent to external servers. All AI models run on-device.

## Updates

This is a research/demo project, so security patches are not guaranteed in real time.
