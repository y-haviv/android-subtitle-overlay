# Contributing

Thank you for your interest in improving this project!

## How to Contribute

- Fork the repository and create a feature branch.
- Make your changes, following Android and Java best practices.
- Add documentation and tests for new features.
- Submit a Pull Request with a clear description of your changes.

## Guidelines

- Keep code readable and maintainable.
- Ensure no breaking changes to existing APIs.
- Respect the GPLv3 license and third-party licenses.
- All contributions are reviewed before merging.

## Community

- Use GitHub Issues for bug reports and feature requests.
- Join discussions to share ideas and feedback.

We welcome contributions from all backgrounds and skill levels!
