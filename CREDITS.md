
# Credits & Acknowledgments

This project leverages outstanding open-source and proprietary libraries:

## Open-Source Libraries

* [Vosk](https://github.com/alphacep/vosk-api) — Real-time speech recognition (Apache 2.0)
* [Whisper.cpp](https://github.com/ggerganov/whisper.cpp) — Speech-to-text transcription (MIT)
* [ONNX Runtime](https://github.com/microsoft/onnxruntime) — Neural network inference (MIT)
* [JTransforms](https://github.com/wendykierp/JTransforms) — Audio processing and FFT (BSD)
* [PyAnnote](https://github.com/pyannote/pyannote-audio) — Speaker embedding extraction via ONNX model (MIT)
* [SentencePiece](https://github.com/google/sentencepiece) — Unsupervised text tokenizer (Experimental integration / Apache 2.0)

## Proprietary & Free Services

* [Google ML Kit](https://developers.google.com/ml-kit) — On-device translation (Google License)
* [Silero Language Classifier](https://github.com/snakers4/silero-models) — Language identification (CC BY-NC 4.0)
* [Picovoice Falcon](https://picovoice.ai/) — Voice activity detection (Experimental integration / Free tier available)
