# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for all contributors and users.

## Guidelines

- Be respectful and considerate in all interactions.
- No harassment, discrimination, or offensive language.
- Help others learn and grow.

## Enforcement

Violations may be reported via GitHub Issues. Maintainers will review and take appropriate action.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, and discussions.
